# v0.2 — графика и ремонтные мини-игры

- Детализированная процедурная квартира и пять семейств текстур.
- Скруглённая мебель, трубы, вентиль, инструменты, новые персонажи.
- Четыре серверные мини-игры: давление, маршрут трубы + момент затяжки,
  покрытие валиком + устранение подтёков, уровень + четыре крепления.
- Рабочие места блокируются на время попытки и освобождаются при отключении.
- Сохранённые настройки по Esc, FX выключены, лаконичный HUD.
- Перезапуск заказа хостом с подтверждением.
- Исправлено взаимодействие капсул игроков при тесном спавне.
- Добавлены проверки правил, маршрутизации UI-ввода и сетевого решения мини-игры.
